#366 — concrete improvement within the existing pipeline

Status: proposed operating application to next authorized production work. No
new controller/schema/runtime, native work, render or extra model call performed.
Director asks how the process improves, not to resume construction. Existing
router-first and grounding/derivation/strategy/challenge/execute/review remain.

##1. Change what is admitted

A work package has one primary audience-visible outcome. Declare affected phase,
reference event range, expert-derived positive criteria, allowed modifications,
frozen unrelated domains, inherited dependencies and outgoing phase interfaces.
This is more than a smaller prompt: execution/review must remain within that
contract or explicitly return to affected planning stage. Necessary horse/rider/
spear/contact coupling stays inside the unit; not one isolated bone per task.

For preparation: stored-energy/readiness through firstlift; whole horse plus
rider/spear support needed to expose causality. No chest sculpt, new clothing,
flag-detail polish, terrain or full-sequence render bundled into that unit.
Accepted identity/look remain protected. Rejected preparation is NOT protected.
The existing SAME motion task and cumulative allowance remain; phase names do
not restart effort or corrections. Scope expansion is explicit internal replan,
not concealed in another repair. No new routine Director algorithm approval.

##2. Replace coarse criteria with positive reference tests

Use existing requirement/reference-aspect/proof fields for each visible feature:
reference event/pose, intended read, current-candidate evidence and explicit
failure. For preparation, ordered feet/support and weight-transfer cues,
head/neck/trunk coupling, and continuous transfer into firstlift. Derive exact
poses/timing from actual reference before construction, not invented numbers.
Presence of foot movement or head lowering alone cannot meet the requirement.

Plan challenge revisits original reference intent and vetoes methods that cannot
change the deficient behavior. The actual365 negative example is a plan that
freezes rejected preparation and only retimes airborne action: it must not be
admitted as a preparation solution. Accepted-source invariance is useful only
for genuinely protected behavior. Existing schema enforcement checks coverage;
it cannot independently discover a bad artistic method from well-formed prose.

##3. Earliest discriminating proof before detail

Author only the phase and its transition boundary first. Inspect pose-family,
support and timing against reference in stable revealing framing, then actual
shot. Keep visual conditions consistent so materials/FX do not conceal movement.
Existing appearance retained; no need to recreate principal identity or lower
accepted same-film quality. Avoid expensive dependent cloth solves or fullcut
renders until the motion source is stable. If pole motion changes, old flag
cache becomes invalid; final resimulation is an integration dependency, not a
second concurrent creative target. No knowingly stale cache presented as ready.

##4. Review the reference outcome, not execution compliance

Separate questions: technical validity; positive silhouette/anatomy; ordered
performance phases; support/contact; interface continuity; whole intended read.
Per requirement, record what reference does, what actual evidence shows, verdict,
and largest remaining discrepancy. An absent bulge cannot positively qualify
chest anatomy. Fixed hand endpoints cannot qualify powerful horse performance.
An intent-level mismatch can fail even when all existing numeric tests pass.

The known365 prep and chest failures are calibration controls. A rubric which
still passes them is inadequate; revise it before a new candidate. This is a
same-agent known-history calibration, not independent or blind qualification.
No new external evaluator/LLM calls are inferred. Technical outcomes and native
availability stay distinct from these source/image judgments.

Actual full-speed AV remains Director-owned under313. Agent frame/source review
can reject visible mismatches but cannot certify biological fluidity. Do not
promise zero Director corrections or claim stronger hashes solve perception.

##5. Meaningful checkpoints and integration

Corrections loop internally within the same unit/allowance. Finished reference-
grounded phase proof, real material choice or actual authority exhaustion is a
handoff; routine implementation errors and incremental improvements are not.
First proposed creative checkpoint is complete preparation through firstlift,
not another whole leader/costume/rear package. No automatic extra Director gate
for each technical interface or diagnostic view. Later checkpoints agree on
meaningful performance outcomes, not an arbitrary elapsed-time cadence.

Accepted unit boundary records outgoing pose, velocity/contact state and consuming
nextphase. Rise must preserve accepted preparation and remain continuous into
crest; landing inherits revised crest energy. Final whole-action proof rechecks
all boundaries, actor/prop/cache dependencies and actual shot. A new downstream
regression reopens its affected unit, not resets the whole build or lowers quality.

##6. Measure improvement with the next production proof

Track reference criteria failing, Director-discovered misses which should have
been caught internally, repeated defect variants, unintended outside-unit edits,
adjacent regressions, correction cycles and work/render occupancy. Retain actual
replans/negative controls. Keep creative Director choices and expected AV review
separate from avoidable technical corrections. No percentage savings forecast.
Smaller scope is a hypothesis until actual preparation improves and escapes fall.
Existing retrospective triggers remain; do not add another orchestration system
before testing this change on real production. Remaining limits/history persist.

## Operational mapping

Grounding: actual reference roles + Director365 rejection and protected accepted
sources. Derivation: one phase, applied animation/animal/contact lenses and positive
requirements. Strategy: allowed-change/freeze set, coupled interfaces, first proof,
replan conditions. Challenge: reject preserve-weak-prep negative example and inspect
original intent. Execute: scoped native changes. Review: exact positive reference
criteria plus adverse controls. Current controller can enforce stage order,
requirements and evidence presence; semantic judgments remain fallible agent duty.
These are proposed requirements to bind into the next real brief, not a claim
that writing this document has already implemented or validated them.
