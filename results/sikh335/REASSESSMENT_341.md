## Process and reusable learning

This time the promised actual neutral proof was performed before bending, and
the visible failure prevented its successor. That correct sequencing is useful,
but the intended output is still incomplete. More planning records did not create
an artistic pass. A successful physics solve can reproduce the wrong rest form;
cloth must bridge anatomical sculpting rather than simply offset and relax it.

Inspect cut-boundary topology and post-modifier skin/cloth clearance, not only
the pre-subdivision collision shell. Keep collision safety, visible neckline
finish and motion compatibility separate. A new isolated scene also changes
which objects are evaluated: compare genuinely evaluated source state, not stale
cached matrices. Track acquisition provenance separately from live linked-file
dependencies; an unused appended library can be dropped on saving.
