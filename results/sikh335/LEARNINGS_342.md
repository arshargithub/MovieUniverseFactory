# Exchange342 — construction and evidence lessons in progress

No whole-character, ensemble or production pass follows from this record.
The ten extra corrections form one shared pool. Source snapshots and original
failures remain in `look01`; accepted assets are unchanged.

## Demonstrated causes and reusable corrections

- **Connectivity before coordinate masks.** The bent neutral cuff spike was a
  medial hand/sleeve vertex moving with the torso. A lateral-coordinate cutoff
  missed it; connected-component membership below the arm junction corrected
  the complete sleeve. Preserve rest coordinates and separate zero-weight points.
  This is demonstrated for one controlled bend, not a general rig qualification.
- **Resolve real pose owners.** Hidden legacy sleeve objects did not offer a
  trustworthy evaluated world state for transfer. Their actual pose-key arrays
  supplied shoulder/elbow/cuff centers. Transport keeps radial form, scales
  only axial length and rejects degenerate or reversed frames. Actual24 shows
  coherent mounted sleeves across selected poses; full-speed quality is pending.
- **Contact is not flattening.** Projecting sash vertices onto coarse clothing
  generated serration. Replacing it with row-wide outermost support produced a
  smooth but floating ribbon at the shoulder.26 instead preserves cross-width
  support slope and bridges only small recesses. This is a tested numerical
  property, still subject to actual images and crest/reverse checks.
- **The underside matters.** A pad surface with a22mm offset and9mm thickness
  still visibly floats. Check underside clearance at intended view and motion,
  not just a nearest-point support distance.26 reduces that margin; no pass yet.
- **A successful donor is a prerequisite, not a finished costume.** Neutral23
  cannot qualify the mounted sash, standing waist, saddle, crown, face or crowd.
  One actual standing representative precedes ensemble propagation.
- **Dependency inventories need actual users.** An orphan appended library
  entry was falsely treated as an active reopen dependency. Actual linked IDs
  are now checked; real image/cache/link dependencies remain guarded. Native21+
  save/reopen verified this correction without deleting provenance.

## Evidence handling failure retained

The22 review initially claimed byte-identical images before reading a comparison
that returned false. That statement was wrong. The immutable review is preserved
alongside `look01/review-c22-erratum.json`; actual images were then inspected and
decoded-pixel equality established. Future evidence-dependent operations must
wait for and inspect the comparison result before recording dependent claims.
File hashes, decoded pixels and perceptual judgment are different assertions.

One26 test command named a nonexistent test file and ran zero tests. The corrected
focused invocation passed33 tests. Failed command output remains on disk; neither
result is artistic approval.

## Where these apply next

Garment transfer planning must retrieve component/pose-owner findings; costume
review must include reverse support and actual animated poses; native persistence
must inspect true external dependencies; all evidence review must wait for the
claimed check's result. These are scoped campaign learnings, not a claim that the
global knowledge index or semantic retrieval calibration has already been updated.
