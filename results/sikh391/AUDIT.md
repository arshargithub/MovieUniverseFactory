# Director391: rearing progress and fifty-cycle audit

## Verdict

**I am not satisfied with overall retrospective/internal-review performance.**
The system now records and contains failures much more reliably. It has not
demonstrated reliable convergence on this horse's forequarter anatomy. This is
partly a strategy/execution-capability gap, not just an absent workflow rule.
More documentation, more cycle approvals, or a different model are not proven
solutions.

The existing images show changes, not steady progressive improvement. I would
not call the overall rearing shot almost finished. Its primary choreography is
separately accepted; its chest/shoulder construction remains a foundational risk.

## Larger patterns and remaining failures

### 1. We optimize a proposed solution before proving the proposed visual form

244projected the original skin toward a mathematical volume before the volume
itself had been visually qualified.246then showed that target was an inflated
blob.249built the dense skinning alternative before a single revealing native
form proof; its dense guard failed first.250correctly moved to a single-pose test.
390spent all ten slots reaching a clean inert rest graft without a native form
test. Some precursor validation was necessary, but the package did not reserve
or reach an early end-to-end visual proof.

These are applications of rules we already had: positive form before precise
fitting/cache/finish. The planning challenge failed to trace what the actual
handler would do before the promised image became available.

### 2. Local reasoning can improve while the production goal stays stationary

Many sub-hypotheses were genuinely different; calling them all coefficient sweeps
would be inaccurate. But seventeen rounds of images still repeat the same
unsupported chest/root failure.384effect records did not translate into one
positive chest proof. We need a stable audience-visible feature ledger across
interventions, not just a disposition for the latest local hypothesis.

The implementation clears a local repeated-attempt streak when a new intervention
is admitted. It retains full history and immediately reopens failed interventions,
so this is not data loss. It does mean a fresh admitted causal story does not by
itself enforce a higher-level decision about repeated failure of the same visual
feature across different methods.

### 3. The challenge is formally separate, but not a demonstrated strong critic

All46preserved planning challenges admit execution. Experimental uncertainty is
legitimate, so a100%admission rate alone is not a defect. However, the concrete
244/249ordering mistakes and the repeated pre-visual investment show insufficient
critical force. The planner and challenger are the same agent; stage separation
does not make their judgments independent. Some causal text is also stale:
ten cycle responses reuse the same “First387test…” cause while submethods change.
More specific changed predictions exist elsewhere in those records; the audit
does not equate copied fields with no reasoning.

### 4. Implementation choices become artificial prerequisites or creative freezes

242's planned expanded tissue domain was refused by an older handler's entire
forearm freeze. That was correct fail-closed transport, but an avoidable mismatch
between plan and implementation.252had to reconcile a stale UnitA-only/internal
weight freeze with the explicitly approved connected topology/binding goal.
Accepted visible performance and method-owned exact internal fields must be
distinguished before dispatch.

Similarly,390serialized all native qualification behind a clean new-graft gate.
The no-change native roundtrip does not apply the graft; its transport risk could
have been qualified independently once a bound valid-format payload existed.
Collision failures must block adoption, not automatically every quarantined
diagnostic or independent control. This is a strategy observation, not permission
to bypass admission or show known failures as ready.

### 5. Source and bookkeeping growth compete with the current problem

The active brief's source bindings approximately doubled over the window.
Each failure is properly retained, but the current execution input and historical
provenance are not sufficiently separated. The latest pass is visibly not
compute/render-bound. We have no basis to calculate how much token or time saving
a context redesign would produce, or claim sprawl caused the bad anatomy.
It is nonetheless an operating burden worth correcting through a separately
reviewed dependency-closure change, without deleting evidence or mandatory rules.

### 6. Disposition labels can contradict actual evidence

218and219record `art_rejected` in native component reviews whose observations
explicitly say structural veto, not artistic image review; neither produced an
image in that cycle. The numerical failure was real. The category is wrong for
measuring visual review performance. This audit uses actual image bindings to
avoid counting them as artistic image-review rounds. Preserve history and append
corrections if the workflow is changed; do not rewrite old failures as passes.

### 7. Knowing what is wrong is not the same capability as constructing anatomy

Fresh images support the critic's rejections. The agent has not demonstrated a
reliable constructive horse-forequarter method under this pose. That is a real
execution-capability gap. More expert-lens labels, new review prose, random
references or a model switch are not evidence that the gap has been crossed.
This does not prove agent-only production impossible: accepted motion and prior
character work remain positive, scoped evidence. It does invalidate confidence
that another large batch of similar corrections will necessarily finish this
asset. The materially different261graft needs a native proof before optimism.

## Recommended next step and narrowly targeted process changes

**Next production package, not authorized here:** one bounded native viability
proof of the existing261graft, under the previously proposed up-to-five shared
cycles. Qualify no-change mesh/shape-key/UV transport, then actual neutral283and
raised339front/side/reverse anatomy, followed by333/346. Inspect the failing view
first and stop the dependent branch if it fails. No more rest refinement, dense
cache, finish or crowd propagation before seeing that result. Exit: coherent
supported whole forequarter, preserved accepted action and no broken interfaces.
Success would justify moving-form/contact work; failure requires a genuinely
different construction proposal, not an automatic large renewal.

**Proposed process amendments, not implemented/adopted by this audit:**

- Keep a compact feature-closure ledger across method changes, separating
  technical progress from native visual proof and final Director acceptance.
- Challenge the actual first executable operation and its output dependencies,
  not only a written “early proof.” Separate truly independent controls from
  self-imposed prerequisite chains.
- Carry unit-level recurrence across admissions. Reassess when different
  representations reproduce the same unclosed visual defect; do not wait only
  for allowance exhaustion. This is evidence-based, not an arbitrary time limit.
- Require image evidence for image-review disposition categories and test the
  critic on suitable known positive and negative controls. Current seventeen
  familiar failures are regression evidence, not a blind accuracy benchmark.
- Distinguish the current executable dependency closure from the complete
  immutable provenance/history archive. Preserve every mandatory source and
  failure; do not merely drop bindings to get under a limit.
- Track scope types within the original shared ceiling: planning/control,
  numerical construction, native visual attempt and moving integration. No
  refunds or counter resets. A successful package is a usable visual result,
  not exhaustion of its approved corrections.
