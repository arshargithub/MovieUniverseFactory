## Carry-forward learning

1. Test the complete lazy import closure and representative CUDA kernels before weight downloads or inference. Two avoidable preparation failures preceded the successful run.
2. Keep inference, dense-source integrity, exporter quality, editable asset conversion and production performance as separate gates.
3. Preserve dense source tensors and material attributes: export damage must be diagnosable without paying for regeneration.
4. A higher-resolution sample can finish while its decoder still exceeds VRAM. Capacity estimates must include peak decode allocations, not only model loading or sampling.
5. Successful cloud teardown, a budget reservation and a verified local file each answer different questions; none proves actual billing or off-device recovery.
6. Qualification fixtures must represent the model's actual output semantics. A closed cube can certify raster/material plumbing while missing unsigned, inconsistently oriented surface sheets. Bind the intended reconstruction branch and test an open-sheet fixture before calling an exporter integration qualified for generated heads.
7. When geometry controls disagree, reassess representation before escalating resolution, GPU size or artistic repair. A failed signed remesh is not evidence that unsigned source geometry cannot work.
8. Separate cold dependency compilation from generation/export runtime. These disposable qualification workers rebuild CUDA extensions; this is useful isolation, not an efficient production deployment. If the route passes, qualify a versioned reusable runtime or wheel cache with hashes, notices and a representative regression asset. This is a proposed next efficiency improvement, not an authorized persistent server or a measured warm-start saving.
9. Correcting export representation can recover coherent shape without solving animation semantics. A textured eyeball-like patch is not an eyeball/lid system; a beard-shaped solid is not a production beard. Qualify those interfaces before full-body construction, and do not mistake generation speed for end-to-end actor production cost.
