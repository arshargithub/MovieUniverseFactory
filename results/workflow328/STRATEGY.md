# Expert lens planning and historical challenge tests

Director328 asks to close the gap between creative intent and executable expert
requirements, and test earlier situations with substantial corrective input.
This pass implements local gates and retrospective counterfactual cases; no
scene construction, provider calls, paid service, render or upload is included.

Outcome: every production beat must explain applicable expertise, derive linked
requirements and execution/proof strategies, and survive a recorded completeness
challenge before execution. Execution records application of those requirements;
review independently returns to original intent and can veto missing requirements.
Retain the existing three model stages, knowledge retrieval and reference roles.
The planning challenge is an explicit reasoning substep inside planning plus
trusted-parent admission, not a falsely claimed independent fourth expert.

Method: extend the existing controller with an expert-plan validator and stage
contracts. A manually scoped intent/beat inventory is authority; the planner
cannot silently drop it. Structural checks establish traceability, not semantic
correctness. Test omitted lens coverage, orphan requirements, missing methods or
proof, stale planning challenges and final-review omissions. Preserve an honest
well-formed-but-wrong control to expose the semantic limit.

Historical cases: route/danger readability, riding performance/contact, narration
and music, and the current Nihang/crowd failure. Keep the initial direction and
later feedback separate, with source IDs. Derive plausible requirements using
only information permitted at the cutoff; flag hindsight contamination because
this agent has already seen the history. These are retrospective regressions,
not blind predictions or measured avoided Director inputs. Test positive plans
and deliberately incomplete variants. Record potentially helpful improvements
as hypotheses, not superior rendered outcomes.

Applicable sources:249 shot brief,321 rejection audit,323 reference/state-machine
contract,326 routing, AU01 reference authority, AU09 interfaces, AU13 judgment.
Generate and read a fresh task packet before implementation. No broad corpus
repinning. Scope to the planning interface and tests rather than a new harness.
Exit: executable gate tests, reproducible historical case assessment, clear
limits and concrete next use in the isolated Nihang/rearing/crowd package.
