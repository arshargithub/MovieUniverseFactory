#319 construction and integration findings

These are observed method failures and corrective tests, not Director acceptance
or a claim that this supporting cast is a generally qualified reusable character.

1. **Reusing topology does not preserve semantic orientation.** The crowd head
   faced+Y while the anatomical garment donor faced-Y. A technically continuous
   surface therefore displayed back musculature as a chest. Bind front, up,
   shoulder, wrist and prop frames explicitly before fitting; inspect the actual
   visible front and a reverse angle. A transform or vertex count cannot certify
   the intended anatomical/garment relationship.
2. **Separate mutable geometry from its construction inputs.** Sequentially
   reading normals while changing adjacent vertices caused the fragmented319
   garment. Freeze coordinates/normals, calculate the complete operation, then
   update. Candidate08's no-inflation control isolated the operation; candidate09
   used a snapshot. Preserve both the failed render and the discriminating
   control, not only the final algorithm.
3. **Interfaces have different owners.** The lower neck must remain attached to
   the torso while the jaw and upper neck follow the head. A collar cannot hide
   a neck moving as one rigid head block. This derivative uses a shot-authored
   blended transform bridge, excluding the jaw. Its current timeline is a test
   condition, not a reusable anatomical rig qualification.
4. **Contact is rendered form, not an inherited label.** Old palms are useful
   animation controllers, but hiding them and adding fingers does not place a
   spear inside the new grip. Trace shaft, finger aperture, thumb, palm, cuff and
   shoulder together. A shield needs a supported rear handle, and an empty hand
   should not be posed as though gripping an invisible weapon. Numeric axis and
   cuff tests supplement, never replace, the visible silhouette.
5. **Construction order is an efficiency issue.** Rebuilding every crowd actor
   before the leader and near-warrior proof passed violated this pass's own
   strategy. The variants remained internal, but avoiding Director interruptions
   alone does not make the work efficient. Next adaptation should first build
   one whole actor plus the relevant contact/pose, then propagate only after
   actual-shot and revealing-angle checks.
6. **Reproducibility needs the recipe as well as hashes.** Builds01–06 retain
   native/render/log evidence but lack complete original source snapshots after
   working code changed. From07 onward bound Python/Markdown is copied at
   dispatch. An input hash without the historical bytes is not exact replay.
7. **Source rights need file-level reconciliation.** An unused local Viking
   facial-hair candidate has CC0 labels in its `.mhclo` files and AGPL3 headers in
   its OBJ files. It was not imported. Do not reuse an earlier blanket
   consistently-labelled claim for those files; resolve the actual dependency
   before reuse. This discrepancy does not apply automatically to the separate
   recorded Blender Studio CC0 anatomical donor used here.
8. **Performance review remains distinct.** A timed-frame sequence can reveal
   seams, abrupt pose changes or a head pointed away from the action. It cannot
   prove convincing real-time motion or sound. Director313's manual AV queue is
   the explicit next judgment stage, not a way to rename known static failures.

Application: reconcile these with the existing `representation`, `anatomy`,
`motion`, `crowd_support`, `au_contact`, `versioning` and `reuse_envelope` actions.
The fresh319 task packet and strategy already bind the broader obligations.
Any retrieval extension must preserve previous pins, name its finite regression
tests and avoid implying independent perceptual calibration.
