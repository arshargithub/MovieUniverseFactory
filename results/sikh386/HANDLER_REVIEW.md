`nihang_anatomy386` adds two fixed registered operations. Export reads the actual
previous-horse cage over183half-frame samples276..367, raw/Basis/weights/edges and
selected anatomical bone endpoints. It temporarily disables subdivision for
same-index cage evaluation, restores frame/subframe/modifier visibility and
checks frozen geometry/actions. Bone endpoints describe the used rig; they do
not prove real muscle mechanics. No new mesh, script execution or source-file
overwrite is performed by export.

The target operation reads only a hash-bound numeric NPZ under the dedicated
anatomy386-targets directory, without pickle/code. Keys, shape, finite values,
mask, time range, displacement and unchanged outside-mask coordinates are
checked. Actual evaluated source positions and rest coordinates must match on
every sample before the reviewed376shot cache writes a reversible derivative.
It preserves source raw shapes/actions and checks playback against actual saved
targets. This is a transport method, not a positive anatomy claim.

Known limitations: the cache is shot-local276..367, its armature is disabled in
the derivative and original correctives retained/muted; outside-window use is
unqualified. UnitD must prove transitions and required consumer handles before
production integration, extending/replacing the representation if necessary.
Nap is hidden in diagnostic form work and must be reattached/qualified later.
Final-surface tack/contact and full-speed judgment remain separate. Do not add
coat detail to hide an invalid surface or promote a precision check into art.

The dispatcher has explicit fixed kind validation; no runtime Python/string or
arbitrary asset script. Tests cover exact dispatch, code/path injection, path
scope, stale file and malformed numeric shapes. Actual first native execution
is still the integration proof, not already qualified by these software tests.
