## Diagnosis and uncertainty
Existing references were enough to reject the gross failure. New near-frontal
rear references reduced uncertainty at the lower-neck/chest/upper-leg junction.
They did not make our construction adequate. The present blocker is achieving
the connected form and its deformation, not an absence of a visual rejection
criterion. Exact muscle mechanics are not proven, and no model superiority claim
follows from this pass. Sol setting is user-reported; usage/cost remain unknown.

Original donor raw vertices and weights match the current raw source. Current
Basis differs by up to168.9mm. Reimporting the same donor would not provide a
clean anatomical alternative. Whole-muscle limb ownership, compact sculpts and
smooth spatial support all failed actual native views. More coefficient sweeps
are not justified by the observed results.

The donor has47 connected components; its main skin has9990 vertices. A spatial
box can accidentally include mane/cards. Component isolation is now part of the
offline cap control; this is an adjacent selection lesson, not proof it caused
every prior failure. A read-only diagnostic accidentally printed a full SQLite
state (about181k output tokens, tool-truncated). That breached bounded-context
practice: future timing queries must explicitly select scalar columns, never
SELECT * from event snapshots. The full output was not used as evidence.

## What the process did and did not improve
Actual failure reviews were recorded before changing bound code. Front/worst
pose vetoes prevented unnecessary coat/contact/full-sequence rendering. Numeric
success, returned native files, source equality and test counts did not become
artistic passes. The failure audit now includes both oblique and side views.

The process still spent too many slots exploring variants of a weak anatomical
foundation. Cycle155's missing native dependency was avoidable planning waste.
The next step must change the foundation being tested, not rename the same local
sculpt. Internal review correctly rejected this pass; it did not solve the work.
