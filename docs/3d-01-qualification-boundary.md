# 3D-01 qualification boundary

The selected 3D-01 campaign demonstrates that Movie Factory can preserve a semantic Blender scene, execute a bounded structured revision through trusted code, retain stable object identities, and verify the requested and protected state. Five selected initial/revision pairs passed the machine gates, and the Director accepted all five.

The experiment used frozen cameras and lights, tight planning ranges, trusted procedural assets, and a revision schema limited to the two expected operations. It therefore does not establish general autonomous cinematography, arbitrary natural-language editing, realistic external asset handling, production-quality geometry, or unrestricted model operation of Blender.

The final disposition is YELLOW because the median full revision-side API cost ratio, `R_api`, is 0.9786 against a GREEN ceiling of 0.75. The edit-planning-only ratio, `R_edit`, is 0.1679 and already GREEN. The difference is primarily the image-review call, so the next economics work should qualify a cheaper reviewer against the existing images before paying for a fresh campaign.

The source binding for the live result is post-hoc because the implementation was not committed when the API calls ran. The sealed evidence records this limit and uses offline replay against a committed reconstruction to establish reproducibility.
