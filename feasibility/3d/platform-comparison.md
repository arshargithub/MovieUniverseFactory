# 3D platform phase boundaries

| Platform | Intended role | This tranche | Qualification evidence required later |
|---|---|---|---|
| Blender 5.2.1 LTS | Persistent content-creation backbone and renderer | Implemented Candidate A; 5/5 live pairs machine-valid with native persistence, exact revision, rendering, replay, recovery and cost evidence | Director reviews; reduce median `R_api` from the YELLOW band if GREEN economics are required |
| Houdini | Procedural/simulation challenger | Interface/design note only | Appropriate license and `hython` access; same static benchmark; procedural-authoring and repair economics |
| Unreal Engine | Complementary real-time stage, Sequencer and renderer | Interface/design note only | Blender import/reimport with stable ID mapping; preserve Unreal-owned cameras/staging; measure preview benefit and handoff loss |

Blender evidence does not establish Houdini or Unreal outcomes. Future comparisons reuse the semantic brief, invariant vocabulary and cost ledger but use native adapters and engine-appropriate visual evaluation. Cross-engine pixel equality is not an acceptance criterion.

Houdini requires a fresh license/entitlement and batch-render review. Unreal requires a fresh macOS feature, Xcode, Editor Python, Sequencer/Movie Render Queue, import-format and license review. Neither is installed or invoked by 3D-01.
